# Proposal

## Why

2026-10-24 のテストで、相方が「前回のお話の要約」を説明しただけの回が、今回の出来事として要約された。さらに、まとめ直しで「配信外で確認したエピローグを報告・共有した」という、実際にはない 10/24 の配信の記録が作られた。要約の指示に、これまでの配信の要約を渡していなかったため、振り返りを新しい出来事と区別できなかった。

## What Changes

- 要約の「すでに与えている情報」に、これまでの配信の要約を加える。過去の配信を振り返って話しただけの内容は、今回の出来事として残さない
- まとめ直しでは、渡した要約に書かれていない出来事を作らない。新しい出来事のない回には見出しを立てない
