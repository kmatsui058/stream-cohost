# Spec Delta

## ADDED Requirements

### Requirement: OBS で選んだ配信枠を読み取る
システムは、配信ソフトにつながったとき、配信の開始・停止を知らされたとき、および 15 秒おきに、配信ソフトの配信設定から配信枠の動画 ID を読み取らなければならない（SHALL）。読み取った動画 ID が前回と違う場合に限り、新しい動画 ID を知らせなければならない（SHALL）。動画 ID が空の場合や、読み取りに失敗した場合は、知らせてはならない（MUST NOT）。

#### Scenario: 起動時に配信枠が選ばれている
- **WHEN** 配信枠を選んだ状態の配信ソフトにつながる
- **THEN** その配信枠の動画 ID が知らされる

#### Scenario: 配信枠を選び直す
- **WHEN** つながった後に、配信ソフトで別の配信枠を選び直す
- **THEN** 15 秒以内に、新しい動画 ID が 1 回だけ知らされる

#### Scenario: 配信枠が選ばれていない
- **WHEN** 配信設定に動画 ID が入っていない
- **THEN** 何も知らされない

#### Scenario: 配信を開始する
- **WHEN** 配信ソフトで配信が開始される
- **THEN** 15 秒を待たずに、配信設定の動画 ID が読み取られる

### Requirement: 対象の配信の決め方
システムは、設定ファイルでの指定、コマンドでの指定、配信ソフトから読み取った動画 ID のうち、最後に起きたものを、チャットの読み取りと配信情報の対象にしなければならない（SHALL）。今の対象と同じ動画 ID が指定された場合は、切り替えてはならない（MUST NOT）。

#### Scenario: 起動後に OBS で配信枠を選ぶ
- **WHEN** 設定ファイルで動画 ID を指定して起動し、その後に配信ソフトで別の配信枠を選ぶ
- **THEN** 対象は配信ソフトで選んだ配信枠に切り替わる

#### Scenario: 同じ配信枠が読み取られ続ける
- **WHEN** 今の対象と同じ動画 ID が配信ソフトから知らされる
- **THEN** チャットの読み取りはやり直されない
