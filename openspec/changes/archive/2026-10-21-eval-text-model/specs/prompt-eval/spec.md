# Spec Delta

## ADDED Requirements

### Requirement: テキストのモデルで評価する
システムは、評価の条件で通常の生成 API が指定された場合、Live の接続を使わずに、同じ指示（persona、今日の配信、直前のやり取り）と同じ入力で、テキストの返事を受け取らなければならない（SHALL）。条件に考える量やツールが指定されていれば、それを生成の設定に含めなければならない（SHALL）。返事に検索の根拠情報が含まれる場合は、ツールを使った痕跡として記録しなければならない（SHALL）。

#### Scenario: テキストのモデルで返事を受け取る
- **WHEN** 条件に通常の生成 API と `gemini-3.8-flash` が指定されている
- **THEN** 指示と入力を渡して生成が 1 回呼ばれ、返事の文章と、返事が終わるまでの時間が記録される

#### Scenario: 考える量と検索を指定する
- **WHEN** 条件に考える量 HIGH と Google 検索が指定され、返事に検索の根拠情報が含まれる
- **THEN** 生成の設定に考える量と検索が含まれ、ツールを使った痕跡が記録される
