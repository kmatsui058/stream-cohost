# Spec Delta

## ADDED Requirements

### Requirement: 召喚中だけ相方を表示する
システムは、相方が召喚されたら画面に相方（立ち絵、または SOUND ONLY 表示）を表示し、退去したら消さなければならない（SHALL）。画面が接続したときは、その時点の召喚の状態を伝えなければならない（SHALL）。

#### Scenario: 召喚と退去
- **WHEN** 相方が召喚され、その後に退去する
- **THEN** 召喚で相方が表示され、退去で消える

#### Scenario: 召喚中に画面が接続する
- **WHEN** 相方が召喚されている間に画面が接続する
- **THEN** 画面は接続直後から相方を表示する
