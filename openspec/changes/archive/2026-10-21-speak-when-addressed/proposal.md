# Proposal

## Why

配信者から「話がつまらない」「割り込まれている、しゃしゃり出てきている感覚が強い」というフィードバックがあった。相方が、配信者の発言すべてに返事をし、さらに質問で話を広げようとするため、配信者の進行を邪魔している。話を広げるのは配信者が主導し、相方は話しかけられたときや、突っ込むべきと明確に判断したときだけ話すべき。一方で、配信中に「トークテーマ用意して」と頼んだときに、まともなネタが出てこなかった。

## What Changes

- 相方が、はっきり話しかけられたとき・突っ込むべきと明確に判断したとき・ネタを頼まれたときだけ話すようにする。それ以外は、決まった合図の言葉（「スルー」）だけを返させ、その返事は読み上げずに捨てる
- 沈黙時に相方から話しかける機能を、既定では無効にする（`IDLE_MIN_SEC` の既定値を 0 に）
- persona を書き直す：質問で話を広げる指示をやめ、話す場面を絞る。ネタを頼まれたときに、今日の配信や画面に結びついた具体的で意外性のあるネタを出せるようにする。長さは 1〜3 文・120 文字程度に緩める（評価の条件 C をもとにする）
- 評価ケースに、「黙るべき／話すべき」の正解と、トークテーマを頼むケース・名前を呼んで話しかけるケースを追加し、正解と合っているかを集計する

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `turn-taking`: 黙る合図の返事を読み上げない要件を追加する
- `operator-controls`: 沈黙時に話しかける機能の既定値を無効に変える
- `prompt-eval`: 評価ケースの正解（黙る／話す）との照合を追加する
