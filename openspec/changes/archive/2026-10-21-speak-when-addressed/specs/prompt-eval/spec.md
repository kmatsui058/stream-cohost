# Spec Delta

## ADDED Requirements

### Requirement: 黙る／話すの正解と照合する
システムは、評価ケースに「黙るべき」か「話すべき」かの正解が書かれている場合、返事が黙る合図だけかどうかを判定し、正解と合っているかを記録しなければならない（SHALL）。条件ごとに、正解と合ったケースの数を集計しなければならない（SHALL）。

#### Scenario: 黙るべき場面で黙った
- **WHEN** 正解が「黙るべき」のケースで、返事が「スルー。」である
- **THEN** 正解と合っていると記録される

#### Scenario: 話すべき場面で黙った
- **WHEN** 正解が「話すべき」のケースで、返事が「スルー」である
- **THEN** 正解と合っていないと記録される
