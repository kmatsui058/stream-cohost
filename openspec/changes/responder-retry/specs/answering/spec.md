# Spec Delta

## MODIFIED Requirements

### Requirement: 問い合わせの失敗で止まらない
システムは、問い合わせがエラーになるか、設定した時間（既定 30 秒）内に返事が届かない場合、同じ内容で 1 回だけやり直さなければならない（SHALL）。やり直しも失敗した場合は、エラーを記録し、何も読み上げずに召喚中のまま次の発話を待たなければならない（SHALL）。問い合わせを始めるときは、送る画面の枚数と、指示と記録の文字数を記録しなければならない（SHALL）。

#### Scenario: 問い合わせがエラーになる
- **WHEN** 召喚中の問い合わせが、やり直しも含めて 2 回ともエラーになる
- **THEN** エラーが記録され、何も読み上げられず、次の発話で再び問い合わせが行われる

#### Scenario: 1 回目だけ返ってこない
- **WHEN** 召喚中の問い合わせの 1 回目が時間切れになり、やり直しで返事が届く
- **THEN** 配信者が話さなくても、やり直しの返事が読み上げられる
