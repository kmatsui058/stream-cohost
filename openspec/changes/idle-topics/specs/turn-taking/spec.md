# Spec Delta

## ADDED Requirements

### Requirement: 話しかける合図は話題を広げる内容にする
システムは、相方から話しかける合図を、話題の切り口が異なる複数の種類の中から選んで送らなければならない（SHALL）。直前に送ったものと同じ種類を続けて送ってはならない（MUST NOT）。どの種類も、感想だけで終わらせず、配信者や視聴者が答えやすい具体的な質問か提案で締めるよう求めなければならない（SHALL）。

#### Scenario: 合図の内容
- **WHEN** 相方から話しかける合図を送る
- **THEN** 合図には、話題の切り口と、具体的な質問か提案で締めるようにという指示が含まれる

#### Scenario: 合図が続く
- **WHEN** 相方から話しかける合図を続けて 10 回送る
- **THEN** 隣り合う 2 回が同じ種類になることはなく、2 種類以上が使われる
