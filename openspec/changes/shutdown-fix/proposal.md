# Proposal

## Why

2026-10-24 のテストで、`q` を押してから終わるまで約 70 秒かかった。終了時の要約（10 秒）のあと、これまでの配信の要約のまとめ直しが 60 秒の上限に達して諦めるまで待っていた。その間、聞く役のセッションを閉じていなかったので、切断されたのを予期しない切断とみなして再接続していた。待っている間に入力した `ｑ`（全角）は不明なコマンド扱いになり、すぐに終わらせる方法もなかった。

## What Changes

- 終了するときは、マイク・画面・チャットを止めたら、まず聞く役のセッションを閉じる（記憶を保存する間に再接続しない）
- 記憶を保存している間は、その旨と最大の待ち時間、もう一度 `q` で保存を打ち切って終わることを表示する
- 終了中にもう一度 `q` を入力したら、その時点の記憶を保存して、すぐに終わる
- コマンドは全角の英数字でも受け付ける
- まとめ直しの上限を 60 秒から、要約と同じ設定（既定 120 秒）にする
