# Spec Delta

## MODIFIED Requirements

### Requirement: 終了処理
システムは、終了するとき、マイクの取り込みを止め、AI とのセッションを閉じてから、記憶を保存し、プロセスを終了しなければならない（SHALL）。記憶を保存している間は、その旨と最大の待ち時間を表示しなければならない（SHALL）。保存の途中でもう一度 `q` を入力されたら、その時点の記憶を保存して、すぐにプロセスを終了しなければならない（SHALL）。割り込みシグナル（Ctrl+C）でも同じ終了処理を行わなければならない（SHALL）。

#### Scenario: q で終了する
- **WHEN** `q` を入力する
- **THEN** マイクの取り込みが止まり、セッションが閉じられ、プロセスが終了する

#### Scenario: 記憶の保存中に再接続しない
- **WHEN** `q` を入力し、記憶を保存している間に聞く役のセッションが切れる
- **THEN** 聞く役は再接続しない

#### Scenario: 保存を待たずに終わる
- **WHEN** `q` を入力し、記憶の保存中にもう一度 `q` を入力する
- **THEN** その時点の記憶が保存され、すぐにプロセスが終了する

#### Scenario: 全角で入力する
- **WHEN** `ｑ` を入力する
- **THEN** `q` と同じく終了する
