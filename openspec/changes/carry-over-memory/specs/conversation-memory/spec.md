# Spec Delta

## ADDED Requirements

### Requirement: 記憶を保存する
システムは、要約を更新するたびと、終了するときに、その時点の要約と直近の発言を、保存日時とともにファイルへ保存しなければならない（SHALL）。終了するときは、保存の前に要約の更新を試みなければならない（SHALL）。要約の更新に失敗するか 8 秒以内に終わらない場合も、その時点の内容を保存しなければならない（SHALL）。

#### Scenario: 終了する
- **WHEN** 記録がある状態で終了する
- **THEN** 要約が更新されてから、要約と直近の発言が保存される

#### Scenario: 終了時に要約が失敗する
- **WHEN** 終了時の要約の更新が失敗する
- **THEN** それまでの要約と発言がそのまま保存される

### Requirement: 前回の記憶を読み込む
システムは、起動するときに保存された記憶があれば読み込み、新しいセッションへの指示に「前回の配信の要約」として、ペルソナの後ろに入れなければならない（SHALL）。保存された内容が読めない場合は、警告を記録して、引き継がずに起動しなければならない（SHALL）。

#### Scenario: 前回の記憶がある
- **WHEN** 前回の要約と直近の発言が保存された状態で起動する
- **THEN** 最初のセッションへの指示に、前回の要約と直近の発言が含まれる

#### Scenario: 保存された内容が壊れている
- **WHEN** 保存ファイルが JSON として読めない状態で起動する
- **THEN** 警告が記録され、ペルソナだけで起動する

### Requirement: 引き継がずに起動する
システムは、引き継がない起動方法で起動されたとき、保存された記憶を読み込んではならない（MUST NOT）。

#### Scenario: テスト用に起動する
- **WHEN** 前回の記憶が保存された状態で、引き継がない起動方法で起動する
- **THEN** 最初のセッションへの指示はペルソナだけになる
