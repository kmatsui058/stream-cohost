# Spec Delta

## MODIFIED Requirements

### Requirement: 設定の既定値を使う
システムは、環境変数で指定されなかった設定項目に、文書化された既定値を使わなければならない（SHALL）。真偽値の設定は `1` か `true` を真として扱わなければならない（SHALL）。

#### Scenario: 何も指定しない
- **WHEN** 必須以外の設定を何も指定せずに起動する
- **THEN** 聞く役のモデル、答える役のモデル、要約のモデル、要約と累積の要約の文字数、召喚の言葉、添える画面の枚数、取り込み間隔、話者、無音の長さなどに、文書化された既定値が使われる

#### Scenario: 真偽値の指定
- **WHEN** 割り込みで黙る設定に `0` を指定する
- **THEN** 割り込みで黙る動作は無効になる

#### Scenario: 声と表示名の既定値
- **WHEN** 話者と表示名を指定せずに起動する
- **THEN** 話者はナースロボ＿タイプＴ ノーマル（VOICEVOX の ID 47）、表示名は「ORÐA-VÁR」になる

#### Scenario: 召喚の言葉を指定する
- **WHEN** 召喚の言葉に「オルダ,ヴァール,オルダちゃん」を指定する
- **THEN** その 3 つが召喚の言葉として使われる
