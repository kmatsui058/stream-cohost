# Spec Delta

## ADDED Requirements

### Requirement: 答える役が検索を使える
システムは、設定で検索が有効（既定）なら、答える役への問い合わせに Google 検索の道具を付けなければならない（SHALL）。無効なら付けてはならない（MUST NOT）。返事が検索を使っていたら、検索した言葉をログに記録しなければならない（SHALL）。

#### Scenario: 検索が有効
- **WHEN** 検索が有効な設定で問い合わせる
- **THEN** 問い合わせに Google 検索の道具が付く

#### Scenario: 検索が無効
- **WHEN** 検索を無効にした設定で問い合わせる
- **THEN** 問い合わせに道具は付かない

#### Scenario: 検索した
- **WHEN** 返事に、検索した言葉「ラグナロクオンライン イベント」が含まれる
- **THEN** その言葉がログに記録される
