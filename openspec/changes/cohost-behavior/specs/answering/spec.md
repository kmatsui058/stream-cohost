# Spec Delta

## ADDED Requirements

### Requirement: 返事を促さない
システムは、答える役への問い合わせに、返事をするよう促す文を付けてはならない（MUST NOT）。問い合わせの最後には、記録の最後の発言に対して、返事をするか黙るか（スルー）を決めるよう求める文だけを付けなければならない（SHALL）。

#### Scenario: 問い合わせの締めの文
- **WHEN** 召喚中に問い合わせる
- **THEN** 問い合わせの最後の文は、返事をするか黙るかを決めるよう求めるもので、返事をするよう促す言葉を含まない

### Requirement: 召喚のきっかけを伝える
システムは、召喚した直後の問い合わせに、召喚のきっかけになった発言（またはチャット）と、反応した召喚の言葉を書き添え、本当に呼ばれたのかを文脈で判断するよう求めなければならない（SHALL）。手で召喚したときは、手で召喚されたことを書き添えなければならない（SHALL）。2 回目以降の問い合わせには書き添えてはならない（MUST NOT）。

#### Scenario: 発言で召喚される
- **WHEN** 配信者の発話「いや、一旦これで戻って、ヴァール城かな、次。」で召喚され、問い合わせる
- **THEN** 問い合わせに、その発言と、反応した言葉「ヴァール」と、本当に呼ばれたのかを判断するよう求める文が含まれる

#### Scenario: 2 回目の問い合わせ
- **WHEN** 召喚後の最初の返事が届いた後に、また問い合わせる
- **THEN** 召喚のきっかけは書き添えられない

### Requirement: 方針を指示に入れる
システムは、答える役への問い合わせのたびに、保存されている方針をすべて、キーワードに関係なく指示に入れなければならない（SHALL）。方針がなければ入れてはならない（MUST NOT）。

#### Scenario: 方針がある
- **WHEN** 方針「攻略の手順やヒントは、はっきり聞かれたときだけ答える」が保存された状態で、「よし。」に対して問い合わせる
- **THEN** 指示にその方針が入る
