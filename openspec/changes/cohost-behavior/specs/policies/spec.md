# Spec Delta

## Purpose

配信者が相方の振る舞いについて伝えた方針（いつも守ること）を保存し、毎回の指示に入れる。要約（流れ）と控え（言葉ごとの出来事）とは分ける。

## ADDED Requirements

### Requirement: 返事の合図で方針を足す
システムは、答える役の返事に `【方針: <内容>】` が含まれていたら、その内容を方針として、日付とともにファイルに保存しなければならない（SHALL）。合図は読み上げに回してはならない（MUST NOT）。同じ内容の方針がすでにあれば、重ねて保存してはならない（MUST NOT）。

#### Scenario: 方針を伝えられる
- **WHEN** 返事が「承知しました。【方針: 攻略の手順やヒントは、はっきり聞かれたときだけ答える】」である
- **THEN** その方針が保存され、「承知しました。」だけが読み上げられる

### Requirement: 方針を毎回入れる
システムは、保存されている方針を、起動時に読み込み、答える役への問い合わせのたびに「マスターの方針」として指示に入れなければならない（SHALL）。方針の合計は設定した文字数（既定 1,000 文字）以内とし、超える場合は新しいものを優先して、入らなかったことを記録しなければならない（SHALL）。

#### Scenario: 起動して問い合わせる
- **WHEN** 方針が 2 件保存された状態で起動し、問い合わせる
- **THEN** 指示に 2 件の方針が「マスターの方針」として入る

#### Scenario: 上限を超える
- **WHEN** 方針の合計が 1,000 文字を超える
- **THEN** 新しいものから 1,000 文字以内で入り、入らなかった方針があったことが記録される
