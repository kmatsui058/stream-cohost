# Spec Delta

## ADDED Requirements

### Requirement: 本番と同じ材料で評価する
システムは、評価ケースに、本番の問い合わせと同じ材料（ペルソナ、方針、召喚のきっかけ、要約以降の記録、締めの文）を組み立てて、答える役のモデルに渡せなければならない（SHALL）。ケースごとに、方針と召喚のきっかけを指定できなければならない（SHALL）。

#### Scenario: 聞き間違いの召喚のケース
- **WHEN** 召喚のきっかけ「ヴァール城かな、次。」（反応した言葉「ヴァール」）を指定したケースを評価する
- **THEN** 答える役への問い合わせに、本番と同じ形で召喚のきっかけが書き添えられる
