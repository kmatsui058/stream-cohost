# Spec Delta

## MODIFIED Requirements

### Requirement: コンソールからの操作
システムは、コンソールに 1 行ずつ入力されたコマンドを次のとおり実行しなければならない（SHALL）。

- `p`：一時停止と再開を切り替える
- `s`：相方の発話を中断する
- `t <文>`：その文を配信者の発話として扱う（記録し、召喚の判定と問い合わせを行う）
- `o`：召喚と退去を切り替える
- `v <動画ID>`：チャットの取得対象を切り替える
- `r`：今すぐ要約する
- `m`：現在の要約と、要約以降の記録を表示する
- `q`：終了する

未知のコマンドには、操作の一覧を表示しなければならない（SHALL）。

#### Scenario: 一時停止して再開する
- **WHEN** `p` を 2 回入力する
- **THEN** 1 回目で一時停止し、2 回目で再開する

#### Scenario: テキストで話しかける
- **WHEN** 待機中に `t オルダ、こんにちは` を入力する
- **THEN** 「オルダ、こんにちは」が配信者の発話として記録され、相方が召喚されて問い合わせが行われる

#### Scenario: 本文のない t
- **WHEN** `t` だけを入力する
- **THEN** 何も記録されず、問い合わせも行われない

#### Scenario: 手で召喚する
- **WHEN** 待機中に `o` を入力する
- **THEN** 相方が召喚される

#### Scenario: 未知のコマンド
- **WHEN** `x` を入力する
- **THEN** 操作の一覧が表示される

#### Scenario: 方針を手で足して消す
- **WHEN** `pl 攻略は聞かれたときだけ` を入力し、`pll` で一覧して、`pld 1` を入力する
- **THEN** 方針が保存されて一覧に出て、その後に消える
