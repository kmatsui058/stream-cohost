# Spec Delta

## ADDED Requirements

### Requirement: 召喚と退去の印を記録に入れる
システムは、相方を召喚したときに「（相方が召喚された）」を、退去したときに「（相方が退去した）」を、記録に入れなければならない（SHALL）。発言やチャットで召喚するときは、召喚の印を、きっかけになった発言（またはチャット）より前に入れなければならない（SHALL）。一時停止中は召喚しないので、印も入れてはならない（MUST NOT）。

#### Scenario: 発言で召喚される
- **WHEN** 待機中に、配信者の発言「オルダ、聞こえる?」で召喚される
- **THEN** 記録は「（相方が召喚された）」、「オルダ、聞こえる?」の順になり、記録の最後はその発言になる

#### Scenario: 退去する
- **WHEN** 退去の合図つきの返事が届き、その後に配信者が話す
- **THEN** 記録は、相方の返事、「（相方が退去した）」、配信者の発言の順になる
