# Spec Delta

## MODIFIED Requirements

### Requirement: 配信者が話し始めたら黙る
システムは、相方が喋っている間に配信者が話した場合の動作を、設定（`duck`・`stop`・`off`、既定 `duck`）に従って行わなければならない（SHALL）。

- `duck`：配信者が話している途中（2 文字以上の途中経過の文字起こし）に相方の声を設定した音量（既定 0.3）まで下げ、配信者の発話が確定するか、途中経過が設定した時間（既定 1,000 ミリ秒）届かなければ元の音量に戻さなければならない（SHALL）。相方の発話を止めてはならない（MUST NOT）
- `stop`：配信者の 2 文字以上の発話が区切られたら、相方の発話を止めなければならない（SHALL）
- `off`：何もしてはならない（MUST NOT）

#### Scenario: 相方の発話中に配信者が話す
- **WHEN** 設定が `stop` で、相方が喋っている間に、配信者の発話「ちょっと待って」が区切られる
- **THEN** 相方の発話が止まる

#### Scenario: 短い雑音
- **WHEN** 設定が `stop` で、相方が喋っている間に、配信者の 1 文字だけの発話が区切られる
- **THEN** 相方の発話は止まらない

#### Scenario: 話しかぶせると声が小さくなる
- **WHEN** 設定が `duck` で、相方が喋っている間に、配信者の途中経過の文字起こし「ちょっと」が届く
- **THEN** 相方の声が 0.3 まで下がり、発話は止まらない

#### Scenario: 話し終えると元に戻る
- **WHEN** 設定が `duck` で声を下げている間に、配信者の発話が確定する
- **THEN** 相方の声が元の音量に戻る

#### Scenario: 途中経過が途切れると元に戻る
- **WHEN** 設定が `duck` で声を下げた後、途中経過が 1,000 ミリ秒届かない
- **THEN** 相方の声が元の音量に戻る

#### Scenario: 何もしない
- **WHEN** 設定が `off` で、相方が喋っている間に配信者が話す
- **THEN** 相方の声も発話も変わらない
