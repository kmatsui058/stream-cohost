# Spec Delta

## ADDED Requirements

### Requirement: 声を小さくする
システムは、声を小さくするよう求められたら、画面に設定した音量（既定 0.3）を、戻すよう求められたら音量 1 を指示しなければならない（SHALL）。音量が変わらない場合は指示を送ってはならない（MUST NOT）。発話が終わるか中断されたときに声を小さくしていたら、音量 1 に戻さなければならない（SHALL）。

#### Scenario: 小さくして戻す
- **WHEN** 喋っている間に、声を小さくするよう 2 回求められ、その後に戻すよう求められる
- **THEN** 画面には音量 0.3 と音量 1 の指示が 1 回ずつ届く

#### Scenario: 小さいまま喋り終える
- **WHEN** 声を小さくしている間に発話が終わる
- **THEN** 画面に音量 1 の指示が届く
