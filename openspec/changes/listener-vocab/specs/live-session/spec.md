# Spec Delta

## MODIFIED Requirements

### Requirement: セッションの設定
システムは、文字起こし専用のモデル（既定 `gemini-3.5-transcribe-live`）とセッションを確立し、応答の種類をテキスト、入力の文字起こしの言語を日本語（`ja-JP`）にしなければならない（SHALL）。設定した用語だけを、聞き取りやすくする語として登録しなければならない（SHALL）。召喚の言葉を自動で登録してはならない（MUST NOT）。登録する語がなければ、登録語を送ってはならない（MUST NOT）。発話の区切りは、設定した無音の長さ（既定 800 ミリ秒）で自動検出させなければならない（SHALL）。

#### Scenario: 既定の設定で接続する
- **WHEN** 設定を変えずにセッションを確立する
- **THEN** 文字起こし専用のモデルに、応答はテキスト、言語は `ja-JP`、登録語なしの設定でセッションが要求される

#### Scenario: 用語を設定する
- **WHEN** 聞き取りやすくする用語に「ニブルヘイム」「ソーサラー」を設定してセッションを確立する
- **THEN** 登録語はその 2 語だけで、召喚の言葉は含まれない
