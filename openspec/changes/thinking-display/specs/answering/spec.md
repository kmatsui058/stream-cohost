# Spec Delta

## ADDED Requirements

### Requirement: 問い合わせ中であることを知らせる
システムは、答える役への問い合わせを始めたら「考え中」になったことを、返事が届くか、やり直しも含めて諦めたら「考え中」が終わったことを知らせなければならない（SHALL）。問い合わせ中に届いた発話でもう 1 回問い合わせるときは、続けて「考え中」としなければならない（SHALL）。

#### Scenario: 召喚して返事が届く
- **WHEN** 名前を呼んで召喚され、問い合わせの返事が届く
- **THEN** 問い合わせを始めたときに考え中になり、返事が届いたときに考え中が終わる

#### Scenario: 問い合わせに失敗する
- **WHEN** 問い合わせがやり直しも含めて失敗する
- **THEN** 考え中が終わる
