# Spec Delta

## ADDED Requirements

### Requirement: 問い合わせ中であることを知らせる
システムは、答える役への問い合わせを始めたら「考え中」になったことを、召喚してから最初の返事が届くまでの問い合わせかどうか（召喚直後か）とともに知らせ、返事が届くか、やり直しも含めて諦めたら「考え中」が終わったことを知らせなければならない（SHALL）。問い合わせ中に届いた発話でもう 1 回問い合わせるときは、続けて「考え中」としなければならない（SHALL）。

#### Scenario: 召喚して返事が届く
- **WHEN** 名前を呼んで召喚され、問い合わせの返事が届く
- **THEN** 問い合わせを始めたときに召喚直後の考え中になり、返事が届いたときに考え中が終わる

#### Scenario: 返事の後にまた問い合わせる
- **WHEN** 召喚後の最初の返事が届いた後に、また問い合わせる
- **THEN** 召喚直後ではない考え中になる

#### Scenario: 問い合わせに失敗する
- **WHEN** 問い合わせがやり直しも含めて失敗する
- **THEN** 考え中が終わる
