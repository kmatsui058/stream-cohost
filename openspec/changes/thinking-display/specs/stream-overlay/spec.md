# Spec Delta

## ADDED Requirements

### Requirement: 考え中を表示する
システムは、考え中になったら画面に知らせ、画面は考え中の間、立ち絵の表情を考え中の画像に切り替え、字幕の位置に点滅する「…」を表示しなければならない（SHALL）。再生中の字幕があるときは「…」を表示してはならない（MUST NOT）。考え中の画像がない場合は、表情を変えずに「…」だけを表示しなければならない（SHALL）。画面が接続したときは、その時点で考え中かどうかを伝えなければならない（SHALL）。

#### Scenario: 考え中になって返事が届く
- **WHEN** 考え中になり、その後に考え中が終わる
- **THEN** 考え中の間は考え中の表情と「…」が表示され、終わると元に戻る

#### Scenario: 再生中に考え中になる
- **WHEN** 字幕を再生している間に考え中になる
- **THEN** 「…」は表示されず、再生が終わってもまだ考え中なら「…」が表示される

#### Scenario: 考え中の画像がない
- **WHEN** 立ち絵フォルダに考え中の画像がない状態で考え中になる
- **THEN** 表情は変わらず、「…」だけが表示される

### Requirement: 考え中の画像を配信する
システムは、立ち絵フォルダの考え中の画像（`misterious.png`）を、立ち絵と同じく決まったファイル名だけで配信しなければならない（SHALL）。画面が接続したときに、考え中の画像があるかどうかを伝えなければならない（SHALL）。

#### Scenario: 考え中の画像を取得する
- **WHEN** 立ち絵フォルダに `misterious.png` がある状態で、その画像を求められる
- **THEN** その画像が返り、接続時の情報で考え中の画像があることが伝えられる
