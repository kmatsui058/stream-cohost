# Spec Delta

## MODIFIED Requirements

### Requirement: 画面での再生と表示
画面は、再生の指示を受けたら、再生中の音声を止めてから新しい音声を再生し、その間は字幕を表示しなければならない（SHALL）。再生音量に応じて SOUND ONLY 表示の明るさを上げ、無音のときは暗く戻さなければならない（SHALL）。再生が終わったら字幕を消し、識別子つきで再生完了を通知しなければならない（SHALL）。音声を再生できなかった場合も再生完了を通知しなければならない（SHALL）。

#### Scenario: 1 文を再生する
- **WHEN** 画面が再生の指示を受ける
- **THEN** 音声が再生され、その間は字幕が表示され、終わると字幕が消えて再生完了が通知される

#### Scenario: 再生音量に応じて明るくなる
- **WHEN** 再生中に音量が上がり、その後に無音になる
- **THEN** 表示は音量に応じて明るくなり、無音になると暗い状態へ戻っていく

#### Scenario: 音声データが壊れている
- **WHEN** 画面がデコードできない音声データを受け取る
- **THEN** 再生完了が通知される

## ADDED Requirements

### Requirement: SOUND ONLY 表示
画面は、立ち絵の画像を使わず、画面の左下に「SOUND ONLY」の文字と相方の表示名を小さく表示しなければならない（SHALL）。喋っていない間は、表示を暗い状態（明るさ 35%）にしておかなければならない（SHALL）。字幕は、この表示の右側に小さく出さなければならない（SHALL）。

#### Scenario: 起動直後
- **WHEN** 画面を開いて、まだ何も再生していない
- **THEN** 左下に「SOUND ONLY」と表示名が暗い状態で表示され、字幕は表示されていない

### Requirement: 表示名を受け取る
システムは、画面が接続したとき、設定された相方の表示名をその画面に送らなければならない（SHALL）。画面は、受け取った表示名を SOUND ONLY 表示に出さなければならない（SHALL）。

#### Scenario: 画面が接続する
- **WHEN** 表示名が「ORÐA-VÁR」に設定された状態で画面が接続する
- **THEN** 画面に表示名が届き、SOUND ONLY 表示に「ORÐA-VÁR」と表示される

## REMOVED Requirements

### Requirement: 立ち絵がないときの仮表示
**Reason**: 立ち絵を使わなくなったため（ナースロボ＿タイプＴの公式立ち絵は、別キャラクターとしての利用と二次配布が規約で禁止されている）。
**Migration**: 「SOUND ONLY 表示」に置き換え。`public/char/` の画像は使われなくなる。
