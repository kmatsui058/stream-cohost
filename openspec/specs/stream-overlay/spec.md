# stream-overlay Specification

## Purpose
配信ソフトのブラウザソースとして重ねる画面を提供し、相方の音声を再生して、字幕と相方の存在を示す表示を出す。再生が終わったら、それを相方の制御側に知らせる。

## Requirements

### Requirement: 画面と素材を配信する
システムは、ローカルホストだけで待ち受け、ルートへのリクエストに配信用の画面を、それ以外のパスには公開フォルダ内のファイルを返さなければならない（SHALL）。公開フォルダの外のファイルを返してはならない（MUST NOT）。存在しないパスには 404 を返さなければならない（SHALL）。

#### Scenario: ルートを開く
- **WHEN** ルートにアクセスする
- **THEN** 配信用の画面の HTML が返される

#### Scenario: 公開フォルダの外を指定する
- **WHEN** 「../」を含むパスで公開フォルダの外のファイルを指定する
- **THEN** ファイルは返されず 404 になる

#### Scenario: 存在しない画像
- **WHEN** 存在しない立ち絵のパスにアクセスする
- **THEN** 404 が返される

### Requirement: 再生の指示と中断を届ける
システムは、接続しているすべての画面に、再生の指示（識別子、字幕の文、音声データ）と中断の指示を届けなければならない（SHALL）。

#### Scenario: 画面が 2 つ接続している
- **WHEN** 画面が 2 つ接続している状態で再生を指示する
- **THEN** 両方の画面に同じ指示が届く

### Requirement: 再生完了を受け取る
システムは、画面から再生完了の通知（識別子つき）を受け取ったら、それを相方の制御側に伝えなければならない（SHALL）。形式が不正な通知は無視しなければならない（SHALL）。

#### Scenario: 不正な通知
- **WHEN** 画面から JSON ではないデータが届く
- **THEN** そのデータは無視され、処理は続く

### Requirement: 画面での再生と表示
画面は、再生の指示を受けたら、再生中の音声を止めてから新しい音声を再生し、その間は字幕を表示しなければならない（SHALL）。再生音量に応じて相方の表示の明るさを上げ、無音のときは暗く戻さなければならない（SHALL）。再生が終わったら字幕を消し、識別子つきで再生完了を通知しなければならない（SHALL）。音声を再生できなかった場合も再生完了を通知しなければならない（SHALL）。

#### Scenario: 1 文を再生する
- **WHEN** 画面が再生の指示を受ける
- **THEN** 音声が再生され、その間は字幕が表示され、終わると字幕が消えて再生完了が通知される

#### Scenario: 再生音量に応じて明るくなる
- **WHEN** 再生中に音量が上がり、その後に無音になる
- **THEN** 表示は音量に応じて明るくなり、無音になると暗い状態へ戻っていく

#### Scenario: 音声データが壊れている
- **WHEN** 画面がデコードできない音声データを受け取る
- **THEN** 再生完了が通知される

### Requirement: 接続を自動で回復する
画面は、相方の制御側との接続が切れたら、再生中の音声を止め、未接続であることを表示し、2 秒ごとに再接続を試みなければならない（SHALL）。

#### Scenario: 制御側を再起動した
- **WHEN** 制御側が停止し、その後起動する
- **THEN** 停止中は未接続と表示され、起動後 2 秒以内に再接続して表示が消える

### Requirement: 立ち絵の表示と表情
画面は、立ち絵がある場合、全身の画像を画面の左下に置き、上半身が見えて下半身は画面の下端で見切れる位置に表示しなければならない（SHALL）。画像を枠で四角く切り取ってはならない（MUST NOT）。喋っていない間は `default` の表情、喋っている間は `smile` の表情にしなければならない（SHALL）。表情は、明るさが一定以上になったら `smile` に、十分に暗く戻ったら `default` に切り替え、音量の細かな揺れで行き来してはならない（MUST NOT）。字幕は立ち絵の右に小さく出さなければならない（SHALL）。

#### Scenario: 喋っていない
- **WHEN** 立ち絵がある状態で、何も再生していない
- **THEN** 左下に `default` の表情が少し暗い状態（明るさ 70%）で表示され、下半身は画面の下端で見切れている

#### Scenario: 喋り始めて、喋り終わる
- **WHEN** 再生が始まって音量が上がり、その後に再生が終わる
- **THEN** 表情は `smile` に変わり、暗く戻ると `default` に戻る

#### Scenario: 音量が小さく揺れる
- **WHEN** 喋っている最中に、音量が一瞬だけ小さくなる
- **THEN** 表情は `smile` のまま変わらない

### Requirement: 立ち絵がないときの SOUND ONLY 表示
画面は、立ち絵がない場合、立ち絵の代わりに画面の左下に「SOUND ONLY」の文字を小さく表示しなければならない（SHALL）。明るさの変化は立ち絵と同じ（喋っていない間は 70%）にしなければならない（SHALL）。

#### Scenario: 立ち絵フォルダを設定していない
- **WHEN** 立ち絵フォルダを設定せずに画面を開く
- **THEN** 左下に「SOUND ONLY」が少し暗い状態（明るさ 70%）で表示される

### Requirement: 立ち絵の画像を配信する
システムは、設定された立ち絵フォルダから、`/character/default.png` と `/character/smile.png` の 2 つだけを配信しなければならない（SHALL）。それ以外のファイルを立ち絵フォルダから返してはならない（MUST NOT）。立ち絵フォルダが未設定なら、これらのパスには 404 を返さなければならない（SHALL）。

#### Scenario: 立ち絵を取得する
- **WHEN** 立ち絵フォルダを設定した状態で `/character/smile.png` にアクセスする
- **THEN** フォルダ内の `smile.png` が返される

#### Scenario: ほかのファイルを指定する
- **WHEN** 立ち絵フォルダを設定した状態で、`/character/angry.png` や `/character/../secret.txt` にアクセスする
- **THEN** 404 が返される

### Requirement: 表示名と立ち絵の有無を受け取る
システムは、画面が接続したとき、設定された相方の表示名と、立ち絵の有無（立ち絵フォルダに `default.png` と `smile.png` の両方があるか）をその画面に送らなければならない（SHALL）。画面は、受け取った表示名を相方の表示に出し、立ち絵の有無に応じて立ち絵か SOUND ONLY かを切り替えなければならない（SHALL）。

#### Scenario: 立ち絵ありで画面が接続する
- **WHEN** 表示名が「ORÐA-VÁR」、立ち絵フォルダに 2 枚がそろった状態で画面が接続する
- **THEN** 画面に表示名と「立ち絵あり」が届き、立ち絵と「ORÐA-VÁR」が表示される

#### Scenario: 立ち絵が片方しかない
- **WHEN** 立ち絵フォルダに `default.png` しかない状態で画面が接続する
- **THEN** 画面に「立ち絵なし」が届き、SOUND ONLY が表示される

### Requirement: 召喚中だけ相方を表示する
システムは、相方が召喚されたら画面に相方（立ち絵、または SOUND ONLY 表示）を表示し、退去したら消さなければならない（SHALL）。召喚された直後は不透明度 0.3 で表示し、召喚されてから最初に音声を再生する直前に不透明度 1 にしなければならない（SHALL）。その後は退去するまで不透明度 1 のままにしなければならない（SHALL）。画面が接続したときは、その時点の召喚の状態を伝えなければならない（SHALL）。

#### Scenario: 召喚と退去
- **WHEN** 相方が召喚され、その後に退去する
- **THEN** 召喚で相方が表示され、退去で消える

#### Scenario: 召喚中に画面が接続する
- **WHEN** 相方が召喚されている間に画面が接続する
- **THEN** 画面は接続直後から相方を表示する

#### Scenario: 召喚されてから話し始める
- **WHEN** 相方が召喚され、その後に最初の返事の音声が届く
- **THEN** 召喚の直後は不透明度 0.3 で表示され、音声の再生を始める直前に不透明度 1 になる

#### Scenario: 話し終わって次の質問を待つ
- **WHEN** 召喚中に返事を読み終える
- **THEN** 退去するまで不透明度 1 のまま表示される

#### Scenario: もう一度召喚される
- **WHEN** 退去した後に、再び召喚される
- **THEN** また不透明度 0.3 から表示される
