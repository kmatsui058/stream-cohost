# operator-controls Specification

## Purpose
配信者が配信中に、コンソールから相方の動作をすぐに制御できるようにする。また、起動に必要な設定が欠けているときは、はっきりわかる形で止める。

## Requirements

### Requirement: コンソールからの操作
システムは、コンソールに 1 行ずつ入力されたコマンドを次のとおり実行しなければならない（SHALL）。

- `p`：一時停止と再開を切り替える
- `s`：相方の発話を中断する
- `t <文>`：その文をテキストで AI に送る
- `v <動画ID>`：チャットの取得対象を切り替える
- `r`：要約してセッションを張り直す
- `m`：現在の要約と直近の発言を表示する
- `q`：終了する

未知のコマンドには、操作の一覧を表示しなければならない（SHALL）。

#### Scenario: 一時停止して再開する
- **WHEN** `p` を 2 回入力する
- **THEN** 1 回目で一時停止し、2 回目で再開する

#### Scenario: テキストで話しかける
- **WHEN** `t こんにちは` を入力する
- **THEN** 「こんにちは」が AI に送られる

#### Scenario: 本文のない t
- **WHEN** `t` だけを入力する
- **THEN** AI には何も送られない

#### Scenario: 未知のコマンド
- **WHEN** `x` を入力する
- **THEN** 操作の一覧が表示される

### Requirement: 終了処理
システムは、終了するとき、マイクの取り込みを止め、AI とのセッションを閉じてから、プロセスを終了しなければならない（SHALL）。割り込みシグナル（Ctrl+C）でも同じ終了処理を行わなければならない（SHALL）。

#### Scenario: q で終了する
- **WHEN** `q` を入力する
- **THEN** マイクの取り込みが止まり、セッションが閉じられ、プロセスが終了する

### Requirement: 必須設定の確認
システムは、AI の API キーかマイクのデバイス名が設定されていない場合、欠けている設定の名前を記録して、何も起動せずに終了しなければならない（SHALL）。

#### Scenario: API キーがない
- **WHEN** AI の API キーを設定せずに起動する
- **THEN** API キーがない旨のエラーが記録され、プロセスが異常終了する

#### Scenario: マイクのデバイス名がない
- **WHEN** マイクのデバイス名を設定せずに起動する
- **THEN** デバイス名がない旨のエラーが記録され、プロセスが異常終了する

### Requirement: 設定の既定値
システムは、環境変数で指定されなかった設定項目に、文書化された既定値を使わなければならない（SHALL）。真偽値の設定は `1` か `true` を真として扱わなければならない（SHALL）。

#### Scenario: 何も指定しない
- **WHEN** 必須以外の設定を何も指定せずに起動する
- **THEN** モデル、取り込み間隔、話者、沈黙の秒数、コンテキスト上限などに、文書化された既定値が使われる

#### Scenario: 真偽値の指定
- **WHEN** 割り込みで黙る設定に `0` を指定する
- **THEN** 割り込みで黙る動作は無効になる

#### Scenario: 声と表示名の既定値
- **WHEN** 話者と表示名を指定せずに起動する
- **THEN** 話者はナースロボ＿タイプＴ ノーマル（VOICEVOX の ID 47）、表示名は「ORÐA-VÁR」になる

#### Scenario: 沈黙時に話しかける機能の既定値
- **WHEN** 沈黙の秒数を指定せずに起動する
- **THEN** 沈黙時に相方から話しかける機能は無効になる（話を広げるのは配信者が主導する）

### Requirement: ログを残す
システムは、すべてのログを、時刻・重要度・発生元の部品名をつけて、コンソールと日付ごとのログファイルの両方に出さなければならない（SHALL）。詳細ログは、設定で有効にしたときだけコンソールに出さなければならない（SHALL）。ファイルには常に出す。

#### Scenario: 詳細ログが無効
- **WHEN** 詳細ログを有効にせずに、詳細ログを 1 件出す
- **THEN** コンソールには出ず、ログファイルには記録される
