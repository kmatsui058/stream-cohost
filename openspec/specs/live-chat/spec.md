# live-chat Specification

## Purpose
YouTube ライブ配信のチャットから新着のコメントを取得し、相方が視聴者のコメントに反応できるようにする。API の利用枠を使い切らないよう、取得の間隔を抑える。

## Requirements

### Requirement: 対象の配信を特定する
システムは、指定された動画 ID から、その配信のライブチャットを特定しなければならない（SHALL）。API キーか動画 ID がない場合は、チャットの取得を行わず、その旨を記録しなければならない（SHALL）。ライブチャットが見つからない場合は、エラーを記録して取得を始めてはならない（MUST NOT）。

#### Scenario: API キーがない
- **WHEN** API キーを設定せずにチャットの取得を始める
- **THEN** 取得は行われず、チャットの読み取りがオフである旨が記録される

#### Scenario: 配信中ではない動画
- **WHEN** ライブチャットを持たない動画 ID を指定する
- **THEN** エラーが記録され、取得は始まらない

### Requirement: 新着コメントだけを届ける
システムは、取得を始めた時点より前のコメントを届けてはならない（MUST NOT）。それ以降に投稿された通常のコメントとスーパーチャットを、投稿者名と本文の組として、届いた順に届けなければならない（SHALL）。それ以外の種類のイベントは届けてはならない（MUST NOT）。

#### Scenario: 取得開始時に過去のコメントがある
- **WHEN** 取得を始めた最初の応答に 10 件のコメントが含まれる
- **THEN** その 10 件は届けられない

#### Scenario: 種類が混在する
- **WHEN** 2 回目以降の応答に、通常のコメント、スーパーチャット、メンバー加入の通知が含まれる
- **THEN** 通常のコメントとスーパーチャットの 2 件だけが届けられる

### Requirement: 取得の間隔
システムは、API が示す待ち時間と、設定した最小間隔（既定 10 秒）の長い方だけ待ってから、次の取得をしなければならない（SHALL）。取得に失敗した場合は 30 秒待ってから再試行しなければならない（SHALL）。

#### Scenario: API が短い待ち時間を示す
- **WHEN** API が 2 秒の待ち時間を示す
- **THEN** 次の取得は 10 秒後に行われる

#### Scenario: 権限エラー
- **WHEN** 取得が 403 で失敗する
- **THEN** 権限かクォータの問題である旨のエラーが記録され、30 秒後に再試行される

### Requirement: 対象の配信を切り替える
システムは、取得中に別の動画 ID で取得を始めた場合、それまでの取得を止めてから新しい配信の取得を始めなければならない（SHALL）。

#### Scenario: 動画 ID を変更する
- **WHEN** 取得中に別の動画 ID を指定する
- **THEN** 以前の配信の取得は行われなくなり、新しい配信の取得が始まる
