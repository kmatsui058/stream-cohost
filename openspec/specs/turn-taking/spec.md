# turn-taking Specification

## Purpose
相方の「召喚 → 会話 → 退去」を管理する。名前で呼ばれたら現れ、召喚中だけ答える役に問い合わせ、配信者が話し始めたら黙り、会話が終わったら姿を消す。

## Requirements

### Requirement: 名前で召喚する
システムは、待機中に、配信者の発話か届いたチャットに召喚の言葉（設定、既定「オルダ」「ヴァール」）が含まれていた場合、相方を召喚し、その発話（またはチャット）に答えるための問い合わせを行わなければならない（SHALL）。待機中は、召喚の言葉を含まない発話やチャットについて、問い合わせを行ってはならない（MUST NOT）。発話とチャットは、待機中も記録しなければならない（SHALL）。

#### Scenario: 名前を呼ぶ
- **WHEN** 待機中に配信者の発話「オルダ、ニブルヘイムってどんな場所?」が区切られる
- **THEN** 相方が召喚され、問い合わせが行われる

#### Scenario: 名前を呼ばない独り言
- **WHEN** 待機中に配信者の発話「合ってるか、こっちで。」が区切られる
- **THEN** 問い合わせは行われず、発話は記録される

#### Scenario: チャットで名前を呼ぶ
- **WHEN** 待機中にチャット「オルダちゃんこんばんは」が届く
- **THEN** 相方が召喚され、問い合わせが行われる

### Requirement: 退去する
システムは、退去するとき、読み上げに回した返事を最後まで読み上げてから待機に戻らなければならない（SHALL）。退去したことを記録しなければならない（SHALL）。待機に戻った後は、再び名前で召喚されるまで問い合わせを行ってはならない（MUST NOT）。

#### Scenario: 退去の合図が届く
- **WHEN** 退去の合図つきの返事が届き、読み上げが終わる
- **THEN** 待機に戻り、その後の名前を含まない発話では問い合わせが行われない

### Requirement: 配信者が話し始めたら黙る
システムは、相方が喋っている間に配信者の 2 文字以上の発話が区切られた場合、相方の発話を止めなければならない（SHALL）。この動作は設定で無効にできなければならない（SHALL）。

#### Scenario: 相方の発話中に配信者が話す
- **WHEN** 相方が喋っている間に、配信者の発話「ちょっと待って」が区切られる
- **THEN** 相方の発話が止まる

#### Scenario: 短い雑音
- **WHEN** 相方が喋っている間に、配信者の 1 文字だけの発話が区切られる
- **THEN** 相方の発話は止まらない

### Requirement: 一時停止中は問い合わせない
システムは、一時停止中、問い合わせと召喚を行ってはならない（MUST NOT）。発話とチャットは記録しなければならない（SHALL）。一時停止したときは、相方の発話を止めなければならない（SHALL）。

#### Scenario: 一時停止中に名前を呼ぶ
- **WHEN** 一時停止中に配信者の発話「オルダ、聞こえる?」が区切られる
- **THEN** 召喚も問い合わせも行われず、発話は記録される
