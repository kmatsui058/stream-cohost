# 作業リスト

配信や試運転で見つかった、まだ手を付けていないこと。着手するときは、振る舞いを変えるものなら OpenSpec の変更を作る。

## 不具合・安定性

- **応答停止の見張り**：2026-10-18 14:16〜14:21 に、接続は生きたまま 5 分半、相方の応答が止まった（自然に復帰。その間もコンテキストは増え続けた）。配信者が話しかけているのに一定時間応答がなければ、自動で張り直す
- **切断予告の連鎖**：2026-10-18 13:25 に、新しい接続の直後に再び切断予告が届き、2 秒に 4 回張り直した。そのたびに沈黙時の合図が再送され、同じ返事が 4 回出た。張り直し直後のクールダウンと、合図を控える処理が必要（沈黙時の合図は今は既定で無効）
- **文字起こしの言語**：短い発話や物音が、日本語以外（「哦」「que」、ローマ字など）として文字起こしされることがある。入力の言語を日本語に固定できないか調べる
- **終了時のログの文言**：終了するときに「OBS から切断されました。5 秒後に再接続します」と出る（実際には再接続しない）

## 機能

- **本番での Google 検索**：評価では有料枠で動いた（月 5,000 回まで無料）。本番のセッションに入れるかを決める
- **答えの深さ**：Live モデルはその場で深く考えにくい。必要なら、考えるモデルで事前に下調べしておく構成を検討する
- **長期の記憶**：配信をまたいで、配信者や常連について分かったことを蓄積する。設計が大きいので、仕様から相談する
