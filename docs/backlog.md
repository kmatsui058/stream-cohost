# 作業リスト

配信や試運転で見つかった、まだ手を付けていないこと。着手するときは、振る舞いを変えるものなら OpenSpec の変更を作る。

## 不具合・安定性

- **ダッキングが効いていない疑い**（barge-in-duck）：2026-10-24 の実機で、話しかぶせても相方の声が小さくなった感じがなかった。次に試すときは `LOG_DEBUG=1` で、話している途中の文字起こし（`🎤…`）が届いているか、`🔉 声を小さくする` が出るかを見る。途中経過が届いていなければ、マイクの音量で判定する方式に切り替える。確認できたら、変更 `barge-in-duck` をアーカイブする
- **文字起こしの言語**：聞く役を ja-JP に固定した（summon-mode）。実際の配信で、日本語以外に誤認識されなくなったか確かめる
- **終了時のログの文言**：終了するときに「OBS から切断されました。5 秒後に再接続します」と出る（実際には再接続しない）

## 機能

- **答える役の Google 検索**：Argon に検索ツールを付けるかを決める（評価で、知識の正確さと遅延を比べてから）
- **長期の記憶**：配信をまたいで、配信者や常連について分かったことを蓄積する。設計が大きいので、仕様から相談する

## 確認・片付け

- 召喚・会話・退去（summon-mode）は 2026-10-24 までにマスターが実機で確認済み。実際の配信で、返事までの時間と 1 配信の費用を実測する
- スモークテストの手順 9（チャット）を、実際の配信で実施して記録する
- Google Drive の運用手順（ずんだもん、緑の丸、SOUND ONLY など古い記述がある）を、Google Docs のコネクタが使えるようになったら更新する
